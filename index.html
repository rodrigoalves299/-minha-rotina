Hoje

Rotina diária

Nos dias sem treino (quarta, sábado e domingo), o horário da academia fica livre para descanso.

Plano semanal

Em casa, o estudo profundo é todo de inglês, com uma habilidade por dia. Python fica para as horas livres no trabalho.

Todo dia: listening em inglês no trajeto. Os flashcards da volta podem misturar vocabulário de inglês e conceitos de Python.

Meta de inglês: fazer um teste de nível agora (o EF SET é gratuito e online) e repetir a cada dois meses.

Trilha de Python

Nas horas livres do trabalho, em rodízio: POO → FastAPI → Banco de dados → IA → Projeto. A cada noite com tempo livre, estude o próximo tema, a partir do tópico onde parou.

POO

  1. Classes, atributos e métodos
  2. Encapsulamento e propriedades
  3. Herança e composição
  4. Dataclasses e type hints
  5. Organizar o código do projeto em classes e módulos

FastAPI

  1. Rotas, parâmetros e respostas
  2. Validação com Pydantic
  3. Organização em routers
  4. Injeção de dependências
  5. Tratamento de erros e testes com pytest

Banco de dados

  1. SQL básico: SELECT, JOIN, GROUP BY
  2. Modelagem de tabelas
  3. SQLAlchemy (modelos e sessões)
  4. Migrações com Alembic
  5. Conectar o banco às rotas da API

IA

  1. Chamar uma API de LLM a partir do Python
  2. Prompts estruturados e saída em JSON
  3. Embeddings e busca por similaridade
  4. RAG simples sobre seus próprios documentos
  5. Expor a IA como um endpoint da API

Projeto

Juntar o que foi estudado nos temas anteriores num projeto real, como o Sherlock ou o Polaris.

Trajetos

Volta (manhã)

  1. Flashcards nos primeiros 20 a 25 minutos, enquanto ainda está alerta.
  2. Depois, inglês em áudio ou descanso, conforme o cansaço.

Ida (noite)

  • Livre: listening de inglês, aula em vídeo de Python ou descanso.

Ferramentas: plugin Spaced Repetition do Obsidian ou Anki. Baixe áudios e vídeos antes, para não depender de sinal.

Sono e treino

  • Escuro e silêncio: cortina blackout ou máscara, tampão de ouvido, celular no silencioso.
  • Cafeína: cortar nas últimas 5 a 6 horas do turno.
  • Chegada: ir direto para o quarto depois do lanche, sem ficar no celular.
  • Lanche pré-treino: comer algo leve ao acordar para não treinar em jejum.
  • Refeição pós-treino: completa, é ela que sustenta o estudo e o início do turno.
  • Folgas: manter o horário de sono o mais próximo possível do normal.

Como começar

  • Comece pela metade: nas duas primeiras semanas, 3 treinos e cerca de 45 min de estudo.
  • Versão mínima: em dia ruim, só os flashcards no trajeto já contam.
  • O sono vem primeiro: se dormiu mal, corte o treino ou o estudo, nunca o sono.
  • Refeições prontas: prepare no fim de semana.
  • Mochila da academia pronta na véspera.
  • Fim de semana protegido: sábado é descanso de verdade, sem culpa.
  • Avaliação em duas semanas: está acordando descansado? O estudo rende? Ajuste.
